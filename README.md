# Go Learning Lab

This repository documents my journey of learning Go from the basics.

The goal of this project is to practice Go step by step, build small examples, and record what I learn along the way.

## Why Go?

I started learning Go because it is widely used in backend development, cloud-native tools, command-line applications, and distributed systems.

Go has a simple syntax, strong performance, and built-in support for concurrency through goroutines and channels. These features make it a practical language for building reliable backend services and developer tools.

## Learning Goals

- Understand basic Go syntax
- Learn how Go modules work
- Practice variables, functions, structs, and interfaces
- Write simple command-line programs
- Practice testing in Go
- Learn goroutines and channels
- Build small backend API examples

## Project Structure

```text
go-learning-lab/
|-- go.mod
|-- README.md
`-- day01-hello/
    `-- main.go
```

## Getting Started

Check your Go version:

```bash
go version
```

Init go mod

```bash
go mod init go-learning-lab
```

Run the Day 1 example:

```bash
go run ./day01-hello
```
